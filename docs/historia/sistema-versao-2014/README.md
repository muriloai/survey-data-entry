# Sistema Original

Esta pasta preserva o código-fonte e os scripts de banco de dados da versão original criada em **2014**
É uma aplicação desktop Windows Forms em C# / .NET Framework e MySQL.

Para conhecer o contexto completo de negócio, métricas e motivos das decisões tomadas na época, veja o documento de **[História do Projeto (HISTORIA.md)](../HISTORIA.md)**

---

## Estrutura de Arquivos

- [`SurveyDataEntry.sln`](SurveyDataEntry.sln) | Solução para abertura no Visual Studio.
- [`SurveyDataEntry/`](SurveyDataEntry/) | Código-fonte da aplicação desktop Windows Forms em C#.
- [`db_mysql_script.sql`](db_mysql_script.sql) | Script DDL para criação da base de dados MySQL (`db_survey_data_entry`).
- [`db_mysql_user.sql`](db_mysql_user.sql) | Script de configuração de usuário e privilégios de acesso no MySQL.
