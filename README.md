# Survey Data Entry

Sistema em desenvolvimento para organizar pesquisas e agilizar o registro de respostas.

## Por que este projeto existe?

O Survey Data Entry surgiu em 2014 para reduzir o tempo de digitação de pesquisas em papel. A nova versão leva essa experiência para a web, preservando o foco em preenchimento rápido e revisão das respostas.

## Situação atual

A reconstrução está em andamento. Já é possível cadastrar clientes e pesquisas, montar questionários e registrar fichas com revisão das respostas. A aplicação possui confirmação de e-mail e recuperação de senha para desenvolvimento local. A interface e os demais recursos continuam em construção; o sistema ainda não está pronto para dados reais.

## Tecnologias

- .NET 10, ASP.NET Core e Blazor
- Entity Framework Core e SQL Server
- ASP.NET Core Identity
